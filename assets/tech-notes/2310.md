# DATA-CENTRIC FINANCIAL LARGE LANGUAGE MODELS

本文提出了一种面向金融领域的数据中心化大型语言模型（FLLM）方法，结合抽象增强推理（Abductive Augmentation Reasoning, AAR），以解决金融分析与解释任务中领域知识复杂、标注数据稀缺的问题。其核心方法体系包含两个关键组件：**金融大型语言模型（FLLM）** 和 **抽象增强推理（AAR）**，二者协同工作，实现对原始金融文本的深度预处理与高质量训练数据的自动生成。

### 1. 数据中心化金融大型语言模型（FLLM）

FLLM 是一个基于**多任务提示微调（multitask prompt-based fine-tuning）** 的专用语言模型，其设计目标不是直接处理原始金融文本，而是对原始金融信息（如政策公告、新闻、研报等）进行系统性预处理与结构化理解，为下游生成任务提供高质量、结构化的输入。FLLM 通过三个关键子任务完成这一过程：

1. **事件匹配与类比（Event Matching and Analogy）**：  
   将输入的金融事件（如新发布的政策）与历史数据库中的相关报告、新闻和案例进行语义匹配，识别出相似或可类比的过往事件与分析材料。该步骤为后续分析提供上下文依据，避免模型“凭空推测”。

2. **观点质量评估（Viewpoint Quality Evaluation）**：  
   对匹配到的材料中的观点句进行质量筛选与评分，识别出具有深度、逻辑性、行业视角而非情绪化或公司个案的高质量分析语句，过滤掉噪音、偏见或低价值内容。评估维度包括是否表达主观观点、是否具有明确多空倾向、是否针对行业整体而非单个公司等。

3. **关键点提取（Key Point Extraction）**：  
   从高质量语句中结构化提取关键信息，包括：行业领域、评估维度（如需求、交易量、市场情绪）、情感倾向（正面/负面）、政策影响范围等，形成可用于生成的结构化提示模板。

通过上述三个子任务，FLLM 将原始、杂乱、非结构化的金融文本，转化为**经过筛选、提炼、结构化、语义增强的提示输入**，相当于为最终的生成模型（如 ChatGPT）构建了一个“金融专家预处理器”。这一过程实现了“数据预理解”（pre-understanding），而非让 LLM 直接处理原始文本，从而显著降低生成模型的认知负荷，提升输出的准确性与专业性。

### 2. 抽象增强推理（AAR）

由于金融领域专业性强，人工标注数据极其稀缺且成本高昂，FLLM 的训练面临数据不足的瓶颈。为此，本文提出**抽象增强推理（AAR）**，一种基于大语言模型的自动化数据增强方法，通过迭代式推理修正 FLLM 的伪标签，生成高质量训练样本。

AAR 包含三个模块，形成一个闭环增强流程，每个模块均调用大语言模型（如 GPT-4）并结合领域专家知识库：

1. **动态知识提问（FAP: Further Analysis Prompting through Dynamic Knowledge Questioning）**：  
   针对 FLLM 生成的初步伪标签（如对某观点句的低质量评分），自动生成一系列针对性的分析性问题。这些问题旨在揭示伪标签中的逻辑漏洞、信息缺失或理解偏差，例如：“该句是否表达了对行业整体而非单个公司的看法？”、“其观点是否有明确的多头/空头倾向？”、“是否使用了主观性词语？”等。FAP 的核心是**通过提问暴露推理盲区**。

2. **一致知识应答（FAE: Further Analysis Enabling through Consistent Knowledge Answering）**：  
   利用领域专家知识库（如金融术语库、政策法规、行业分析框架），对 FAP 生成的问题进行专业、一致、逻辑严密的回答。该步骤确保推理过程基于真实、权威的金融知识，而非模型的幻觉，从而提供**知识驱动的修正依据**。

3. **知识融合输出修正（FADOM: Further Analysis-Driven Output Modification through Knowledge-Enriched Question-Answer Fusion）**：  
   将原始伪标签、FAP 的问题和 FAE 的答案进行融合，系统性地修正原始输出。例如，若一个观点句被 FLLM 初步评为“差”，但 FAP/FAE 证明其满足“表达行业整体观点”和“有明确多空倾向”两项标准，则修正为“较好”；若三项标准均满足，则修正为“好”。FADOM 通过规则化融合，生成**更准确、更符合专家判断的高质量标签**。

AAR 的本质是**将抽象推理（abductive reasoning）过程自动化**：从一个初步观察（FLLM 的伪标签）出发，通过生成可能的解释（FAP），验证解释的合理性（FAE），并最终选择最佳解释以修正输出（FADOM）。这一过程不依赖人工标注，而是利用大模型的语义推理能力与专家知识库，实现**低成本、高精度的训练数据自生成**。

### 3. 方法整体流程

1. **初始阶段**：使用少量专家标注数据微调一个基础 FLLM。
2. **数据增强阶段**：将大量未标注金融文本输入 FLLM，生成伪标签；再通过 AAR 模块（FAP→FAE→FADOM）对伪标签进行迭代修正，生成高质量标注数据。
3. **模型训练阶段**：将原始小规模标注数据与 AAR 生成的增强数据合并，用于重新微调 FLLM，提升其在三个子任务上的性能。
4. **推理阶段**：将新的金融输入通过优化后的 FLLM 进行三步预处理，生成结构化提示，输入至通用 LLM（如 ChatGPT）生成最终分析报告。

### 4. 方法优势

- **数据中心化**：将“知识注入”从模型参数层面转移到数据层面，通过预处理降低 LLM 的推理负担，提升任务适配性。
- **解决数据稀缺**：AAR 实现了在无大量人工标注前提下，自动生成高质量训练数据，突破金融领域标注瓶颈。
- **领域专业化**：通过融合专家知识库与多任务结构化处理，使模型输出具备金融专家级别的逻辑性与专业性。
- **可扩展性强**：AAR 的模块化设计可适配其他专业领域（如医疗、法律），只需替换知识库与任务定义。

综上，本文方法通过 FLLM 实现金融文本的深度结构化预处理，通过 AAR 实现训练数据的自动化高质量增强，二者结合构建了一种高效、可扩展、面向复杂专业领域的 LLM 应用范式。
