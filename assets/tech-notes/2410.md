# Generation of synthetic financial time series by diffusion models

本文提出的方法是一种基于去噪扩散概率模型（Denoising Diffusion Probabilistic Models, DDPM）与小波变换（Wavelet Transformation）相结合的合成金融时间序列生成框架，旨在同时生成并准确复现多个相互关联的金融时间序列（股票价格对数收益、买卖价差、交易量）及其所遵循的“风格化事实”（stylized facts）。该方法的核心思想是将一维金融时间序列转化为二维彩色图像，利用DDPM在图像生成方面的强大能力学习并生成复杂的市场动态，再通过逆变换还原为真实感强的金融时间序列。具体步骤如下：

1. **金融时间序列预处理**：  
   - 输入为同步观测的三个金融时间序列：股票价格（用于计算对数收益）、买卖价差（bid-ask spread）和交易量（trading volume）。  
   - 为便于后续小波变换，对每个时间序列进行镜像扩展（mirror expansion），使其长度标准化为 $2^n$（本文中为512，对应一个交易日390分钟数据扩展后的长度）。  
   - 对股票价格计算对数收益：$\log(S_t / S_{t-1})$，以消除非平稳性并标准化不同股票间的尺度差异。  
   - 对交易量应用反双曲正弦（arsinh）变换：$\text{arsinh}(x) = \ln(x + \sqrt{x^2 + 1})$，以在保留大值对数尺度特性的同时，避免对零值或极小值取对数时的数值不稳定。  
   - 对所有三个序列应用幂变换（power transformation）：$\frac{(X_t - \mu(X_t))^{1/p}}{\sigma(X_t)}$，其中幂指数 $p$ 可针对不同序列独立设定（本文中对数收益取 $p=1.5$，价差和交易量取 $p=1.0$）。  
   - 采用Winsorization（截尾处理）剔除异常值：将超出 $\pm 10\sigma$ 的值替换为 $\pm 10\sigma$，以提升训练稳定性。

2. **小波变换与图像化（Pixel Filling）**：  
   - 对预处理后的每个一维时间序列应用离散小波变换（DWT），选用Haar小波作为母小波。  
   - DWT输出多层系数：第0层为近似系数（低频），第1层为一个细节系数，第2层为两个，第3层为四个，依此类推，直至第$(n-1)$层。  
   - 将每层系数按其阶数映射为图像的行：第$k$阶系数对应图像的第$k$行。  
   - 每阶系数的长度为 $2^l$，则该行被划分为 $2^l$ 个像素块，每个块填充为该系数的相同值，形成一幅灰度图像。  
   - 将三个序列（对数收益、价差、交易量）分别生成的三幅灰度图像，作为红（R）、绿（G）、蓝（B）三个通道，合成一幅三通道彩色图像。该图像完整编码了三个时间序列在多尺度上的时空结构。

3. **DDPM模型训练与图像生成**：  
   - 使用合成的彩色图像作为训练数据，训练DDPM模型。  
   - DDPM采用U-Net架构，包含多级卷积与注意力机制，通道维度设置为128-128-256-256-512，与Hugging Face官方DDPM教程一致。  
   - DDPM通过前向扩散过程逐步向图像添加高斯噪声，再通过反向去噪过程学习从噪声中恢复原始图像的分布。  
   - 训练目标是学习数据分布 $p_{\text{data}}(\mathbf{x})$，使得模型能够从纯噪声中生成与训练图像统计特性一致的新图像。

4. **合成时间序列的生成与还原**：  
   - 训练完成后，从标准高斯噪声中采样，通过DDPM的反向去噪过程生成新的三通道彩色图像。  
   - 对生成的彩色图像，分别提取R、G、B三个通道，作为三个独立的灰度图像。  
   - 对每个灰度图像执行逆小波变换（inverse DWT），恢复为一维系数序列。  
   - 对恢复的序列执行预处理的逆操作：逆幂变换、逆arsinh变换、逆标准化，还原为原始尺度的金融时间序列（对数收益、价差、交易量）。  
   - 最终输出为三个同步的、具有真实市场统计特性的合成金融时间序列。

该方法的关键创新在于：  
- 利用小波变换将多维时间序列的多尺度结构（从宏观趋势到微观波动）编码为二维图像的空间结构，使DDPM能够通过图像卷积机制有效捕捉金融时间序列中的长程依赖与非线性动态；  
- 利用RGB三通道同时建模三个相互关联的金融变量，使DDPM在生成过程中自然学习并保留其交叉相关性（如波动率与交易量正相关、价差与交易量负相关）；  
- 小波图像的左半部分编码市场开盘时的高频微观结构，右半部分编码收盘时的高频结构，中间部分编码日内低频趋势，从而精准复现了“U型”日内季节性模式（开盘与收盘高波动、高交易量、宽价差，午间低值）。

整个流程实现了从原始金融数据 → 小波图像 → DDPM生成图像 → 逆变换 → 合成金融时间序列的端到端生成，无需对数据分布做参数化假设，且能同时满足多个风格化事实，显著优于现有GAN和VAE方法。
