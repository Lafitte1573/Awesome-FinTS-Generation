# Auto-Generating Earnings Report Analysis via an Augmented LLM

本文提出的方法是一种名为“检索增强指令生成”（Retrieval-Augmented Instruction Data Generation）的创新框架，旨在通过构建高质量、领域特定的指令数据，微调大型语言模型（LLM），以实现对收益报告分析的自动化生成。该方法结合了检索增强生成（RAG）与指令微调（Instruction Tuning），核心目标是克服通用LLM在金融领域语义理解与上下文关联上的不足，从而生成准确、专业、上下文一致的收益报告分析。

方法的具体步骤如下：

1. **金融文档预处理与索引**：  
   首先，将原始金融文档（如季度财报、新闻稿、电话会议纪要）分割为多个文本块（text chunks）。这些文本块作为后续指令生成的上下文基础。随后，使用嵌入模型（embedding model）将每个文本块编码为向量，并存入向量数据库（如ChromaDB），建立可高效检索的金融领域上下文索引。

2. **种子指令设计**：  
   为引导教师LLM（如GPT-3.5-turbo）生成高质量、多样化的金融指令数据，研究设计了六类种子指令（seed instructions），涵盖收益分析的核心维度：  
   - 公司核心信息（如行业、业务）  
   - 关键财务指标（如收入、利润）  
   - 横向对比（如与同行比较）  
   - 未来展望（如下一季度收入预测）  
   - 总结（如高管陈述摘要）  
   - 分析（如基于数据的深度解读）  
   每类指令均附带具体示例和关联的文档类型（如财报、新闻稿），确保生成的问答对具备金融语境的精确性。

3. **检索增强的指令数据生成**：  
   在生成每一条指令-答案对时，系统并非直接使用原始文档，而是采用“检索-生成”机制：  
   - 对于每一个种子指令模板，系统从向量数据库中检索与该指令语义最相关的Top-K个文本块（上下文片段）；  
   - 将检索到的上下文与原始指令模板拼接，形成增强后的提示（prompt）；  
   - 将此增强提示输入教师LLM（GPT-3.5-turbo），要求其基于检索到的上下文生成一个自然语言问题及其对应答案。  
   此过程确保生成的每个问答对都严格基于真实财务文本内容，避免了通用LLM凭空编造或脱离上下文的问题，显著提升数据的真实性与领域相关性。

4. **数据规模与格式**：  
   在实验中，每段文本块生成10个指令-答案对（num_questions_per_chunk=10），从NVIDIA和AMD的2023年第三季度财报中生成共计800条训练样本。每条训练样本格式为：  
   ```
   [Context]: [检索到的财务文本片段]  
   [Instruction]: [增强后的指令问题]  
   [Response]: [教师LLM生成的答案]
   ```

5. **模型微调**：  
   以开源LLM Llama-2-7b作为基础模型，采用LoRA（Low-Rank Adaptation）方法进行高效参数微调，并结合QLoRA的4-bit量化技术以降低显存占用、加速训练。微调仅更新低秩适配器参数，而非整个模型，从而在有限计算资源下实现高效领域适配。

6. **评估与部署**：  
   微调后的模型被用于生成对第三方公司（Broadcom Inc.）收益报告的分析。在评估中，模型接收与训练相同的上下文输入，并输出对关键绩效指标（KPI）如季度股息、收入趋势等的分析。通过与Llama-2-7b和GPT-3.5的对比，验证其在正确性（Correctness）和语义相似性（Semantic Similarity）上的优越表现。

综上，本文方法的核心创新在于：**将检索增强机制嵌入指令数据生成阶段，使指令数据的构建过程本身即被金融上下文所约束和引导，从而生成高度专业化、真实可靠、可直接用于微调的金融指令数据集**。该方法不依赖昂贵的标注数据，而是利用教师LLM与检索系统协同生成高质量训练样本，为构建低成本、高性能的金融专用LLM提供了可复用的范式。
