# Data Augmentation Strategies for Improving Time Series Classification Accuracy

本文提出了一种系统性评估时间序列分类中数据增强技术有效性的方法，核心目标是识别在何种数据特性下特定增强方法能显著提升分类准确率，尤其针对MiniRocket分类器在85个UCR时间序列数据集上的表现。方法论包含以下关键步骤：

1. **实验框架与基准模型**：  
   采用MiniRocket作为核心分类器，因其兼具高准确率与极高计算效率（比ROCKET快75倍），且具有确定性（可选完全确定模式），适合作为评估数据增强影响的稳定基准。所有实验均使用sktime框架实现，确保可复现性，并采用UCR存档提供的预定义训练/测试划分，避免因数据划分差异引入偏差。

2. **数据增强方法选择与参数化**：  
   基于文献[23]提出的分类体系，选取8种具有代表性的数据增强技术，覆盖四大类：  
   - **随机变换-幅度**：幅度扭曲（Magnitude Warping），通过三次样条生成平滑曲线乘以原始序列，引入幅度波动；  
   - **随机变换-时间**：窗口扭曲（Window Warping），使用三次样条路径拉伸/压缩时间轴，改变时间结构；  
   - **随机变换-频率**：傅里叶变换（Fourier Transform）与短时傅里叶变换（STFT），在频域修改振幅/相位后逆变换回时域，STFT进一步捕捉局部频谱变化；  
   - **模式混合-幅度**：SMOTE，对少数类样本进行线性插值生成新样本；  
   - **模式混合-时间**：判别引导扭曲（DGW），利用判别性强的“教师”模式指导DTW扭曲，生成更具区分性的样本；  
   - **模式混合-组合**：加权动态时间规整质心平均（wDBA），通过DTW计算多个序列的加权平均，保留类内关键形状特征；  
   - **分解**：双指数平滑（Double Exponential Smoothing），分离趋势与水平分量后外推生成新序列。  

   每种方法均设置多个参数组合（如wDBA的batch_size ∈ {1,2,…,8}，Magnitude Warping的sigma ∈ {0.1,0.3,…,0.9}），总计165种参数配置，确保对增强效果的全面探索。

3. **数据集特性分析**：  
   对85个UCR数据集进行多维特征标注，包括：数据类型（图像、光谱、传感器、模拟、设备、运动、ECG）、是否多分类、序列长度（长/短）、数据规模（大/小）、是否存在类别不平衡、是否含噪声、是否平稳。该标注用于后续关联增强效果与数据特性。

4. **实验流程与评估**：  
   对每个数据集，依次应用8种增强方法的165种参数配置，生成增强后数据集，输入MiniRocket进行分类，记录准确率。每个数据集共执行165次增强实验。以原始数据（无增强）的MiniRocket准确率为基准，计算每种增强配置相对于基准的准确率差值。最终，对每个增强方法，计算其在所有参数设置下平均准确率差值，并统计其在85个数据集中“获胜”次数（即准确率高于基准的次数）。

5. **结果分析策略**：  
   - **整体性能**：计算每种增强方法的平均准确率差值，评估其全局影响；  
   - **个体表现**：识别每个数据集上表现最佳的增强方法，统计各方法的“获胜”次数（Table 5）；  
   - **特性关联分析**：将“获胜”数据集按其特性分组，计算各类别中“高表现”（Top Performer，前25%数据集）和“低表现”（Low Performer，后25%数据集）的比例（Table 2 & Table 3），揭示增强效果与数据特征（如数据类型、规模、噪声、ECG等）的关联模式。

该方法的核心创新在于：**不追求单一“最优”增强方法，而是通过大规模、参数化、多维度的实验，建立数据集特性与增强方法有效性之间的映射关系，为实践者提供“何时、对何种数据使用何种增强”的决策依据**。
