# A semi-heterogeneous ensemble forecasting method for stock returns based on sentiment analysis

本文提出了一种基于情感分析的半异构集成预测方法，用于预测标普500指数收益率。该方法通过融合情感信息、注意力机制、主成分分析（PCA）与变量扰动策略，构建具有高准确性与高多样性的基模型池，并通过半异构集成策略实现更优的预测性能。其核心方法体系可系统分解为以下三个关键组成部分：

---

### **1. 监督情感指数构建（Supervised Sentiment Index Construction）**

为从金融文本中提取具有预测能力的情感特征，本文提出一种融合注意力机制的监督式PCA方法（attention-PCA），其流程如下：

#### **(1) 情感词典构建**
- 数据来源：从《纽约时报》（NYT）和《华尔街日报》（WSJ）1992年1月至2018年11月的月度金融/经济类文章中收集文本。
- 预处理：去除停用词、数字、双字符词、连字符，进行词干提取，并识别二元词组（collocations）。
- 特征表示：采用TF-IDF方法计算每个词（包括单字与二元词组）在每月文本中的频率，形成一个 $ N \times T $ 的词频矩阵 $ X $，其中 $ N $ 为词汇数（1630个），$ T $ 为时间点数（323个月）。
- 维度筛选：仅保留TF-IDF排名前100的词汇，以降低噪声与冗余。

#### **(2) 监督注意力权重分配**
- 为克服传统无监督PCA忽略预测目标的问题，引入监督机制：使用回归模型（OLS、Ridge、LASSO、Elastic Net）计算每个词汇变量 $ X_i $ 与目标变量（S&P 500月度收益率 $ Y $）之间的回归系数 $ c_i $。
- $ c_i $ 的符号表示情感方向：
  - $ c_i > 0 $：正向情感词（pos）；
  - $ c_i < 0 $：负向情感词（neg）；
  - $ c_i = 0 $：无显著影响词，予以剔除。
- 基于回归系数构建四类情感变量集合：pos、neg、pos+neg、all。
- 对每类集合中的词汇，应用 **Softmax函数** 对回归系数 $ c_i $ 进行归一化，生成注意力权重 $ \omega_i $：
  $$
  \omega_i = \frac{\exp(c_i)}{\sum_{i=1}^M \exp(c_i)}, \quad \sum_{i=1}^M \omega_i = 1
  $$
- 将原始词频矩阵 $ X $ 按注意力权重加权，得到加权矩阵：
  $$
  X^* = (\omega_1 X_1, \omega_2 X_2, \dots, \omega_M X_M)
  $$
  该加权过程赋予预测能力更强的词汇更高权重，增强模型对关键情感信号的敏感性。

#### **(3) 监督PCA降维生成情感指数**
- 对加权后的 $ X^* $ 矩阵（每类变量集合独立处理）进行PCA，提取第一主成分作为该类情感指数（如“pos+neg-att-PCA指数”）。
- 该情感指数是融合了词频、情感方向与预测重要性的综合特征，替代原始高维词频，作为后续预测模型的输入。

---

### **2. 多样化基模型池生成（Diversified Base Model Pool Generation）**

为构建高准确性与高多样性的基模型集合，本文通过以下方式生成多个基预测模型：

#### **(1) 基模型算法选择**
- 采用两类代表性预测模型：
  - **多元线性回归（MLR）**：捕捉线性关系，解释性强；
  - **反向传播神经网络（BPNN）**：三层网络，隐藏层10节点，激活函数为ReLU，捕捉非线性动态。
- 每类模型分别与四种回归方法（OLS、Ridge、LASSO、Elastic Net）结合，形成8种“Att-XXX”组合（如Att-OLS、Att-LASSO等）。

#### **(2) 多样性增强机制**
- **输入多样性**：为每种回归方法（如LASSO）生成四个情感指数输入（pos、neg、pos+neg、all），每个指数由attention-PCA独立生成，提供不同视角的情感表征。
- **算法多样性**：MLR与BPNN分别建模线性与非线性关系，形成算法层面的异构性。
- **扰动多样性**：通过在相同算法框架下，使用不同情感指数输入与不同回归正则化策略（L1/L2），实现**同一算法内部的参数与输入扰动**，从而在不增加模型种类的前提下，显著提升模型多样性。
- 最终生成一个包含16个基模型的池（8种回归方法 × 2种预测模型），每个模型均使用attention-PCA生成的情感指数作为输入。

---

### **3. 半异构集成预测框架（Semi-Heterogeneous Ensemble Framework）**

为整合基模型并优化预测性能，本文设计一种兼具同质与异质特性的集成策略：

#### **(1) 半异构结构设计**
- **异质性体现**：模型来自不同算法（MLR与BPNN），具备算法层面的异构性。
- **同质性体现**：同一算法（如MLR）下使用多种正则化方法（LASSO、Elastic Net）与情感指数输入，形成**内部扰动**，而非完全独立的算法。
- 该结构避免了全异构集成所需的庞大模型池，同时显著超越同质集成的多样性，实现“**中等规模、高多样性、高准确性**”的平衡。

#### **(2) 集成权重优化**
- 采用**基于预测性能的加权策略**：模型权重根据其在验证集上的表现（如RMSE、MAE）自适应分配，表现优者权重更高。
- 为优化权重，可采用启发式算法（如人工蜂群算法ABC）搜索最优权重向量，以最小化集成预测误差。

#### **(3) 多样性评估机制**
- 使用**偏差-方差-协方差分解**分析集成误差来源：
  $$
  \text{err}(H) = \overline{\text{bias}}(H)^2 + \frac{1}{m} \overline{\text{variance}}(H) + \left(1 - \frac{1}{m}\right) \overline{\text{covariance}}(H)
  $$
  协方差项越小，模型间相关性越低，多样性越高。
- 引入**双故障（Double-Fault, DF）度量**评估模型间错误重叠程度：
  $$
  DF_{i,j} = \frac{1}{N} \sum_{t=1}^N \mathbb{I}(err_{t,i} > \text{mean}(err_{t,k}) \text{ and } err_{t,j} > \text{mean}(err_{t,k}))
  $$
  DF值越低，表示模型间错误不重合，多样性越高。

---

### **总结：方法创新点**

1. **监督注意力-PCA**：首次将回归系数作为注意力权重引入PCA，实现情感特征的有监督降维，提升预测相关性。
2. **加权数据增强**：通过注意力权重对高频预测词赋予更高噪声，增强训练数据的多样性与泛化能力。
3. **半异构基模型池**：通过“算法异构 + 内部扰动”策略，在有限模型数量下实现高多样性，避免过拟合。
4. **情感组合优化**：证实“正负情感词组合（pos+neg）”构建的情感指数显著优于单一情感词或全词集合。
5. **可解释性增强**：回归系数与注意力权重提供模型决策的可解释路径，增强金融应用可信度。

该方法通过系统整合文本情感、监督降维、扰动建模与半异构集成，显著提升了S&P 500月度收益率预测的准确性（RMSE、MAE下降）与方向预测能力（Dstat提升），并在多个评估指标上优于传统单模型与基准方法。
