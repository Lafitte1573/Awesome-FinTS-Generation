# CoFinDiff: Controllable Financial Diffusion Model for Time Series Generation

本文提出的CoFinDiff（Controllable Financial Diffusion Model）是一种基于条件扩散模型的金融时间序列生成方法，旨在生成同时满足金融数据典型特征（stylized facts）并能精确控制生成条件（如趋势与波动率）的合成金融数据。其核心思想是将金融价格序列转化为图像形式，并通过引入趋势与已实现波动率作为条件，利用交叉注意力机制将条件信息嵌入扩散模型的生成过程中，从而实现对合成数据的精准控制。

### 1. 输入数据处理

CoFinDiff的输入为股票价格序列 $ p_t $，其中 $ t \in \{0, ..., T\} $。首先，计算对数收益率序列：
$$
r_t = \log p_t - \log p_{t-1}, \quad t \in \{1, ..., T\}
$$
为便于建模，对 $ r_t $ 进行标准化，使其均值为0、方差为1，得到 $ \tilde{r}_t $。

接着，采用Haar小波变换（Haar wavelet transform）将标准化后的对数收益率序列 $ \tilde{r}_t $ 转换为二维图像格式。该变换将一维时间序列分解为不同尺度的系数，并将其排列为矩形图像，从而适配原本为图像设计的扩散模型架构。

同时，计算两个关键条件变量，作为生成过程的控制信号：
- **趋势（Trend）** $ \hat{\mu} = \sum_{t=1}^T r_t $：表示整个序列的累积收益率，反映价格的总体方向。
- **已实现波动率（Realized Volatility）** $ \hat{\sigma} = \sqrt{\sum_{t=1}^T r_t^2} $：衡量价格波动的幅度。

为适配模型输入，对 $ \hat{\mu} $ 和 $ \hat{\sigma} $ 进行仿射变换和卷积处理，生成用于交叉注意力机制的Key和Value向量。

### 2. 训练阶段

CoFinDiff采用条件扩散模型（conditional diffusion model）进行训练。扩散模型的基本结构遵循Denoising Diffusion Probabilistic Model（DDPM）[Ho et al., 2020]，包含前向加噪过程与反向去噪过程。

在训练过程中，模型以Haar小波变换后的图像作为输入数据 $ x $，以计算得到的趋势 $ \hat{\mu} $ 和已实现波动率 $ \hat{\sigma} $ 作为条件 $ c $。通过在扩散模型的U-Net架构中引入**交叉注意力机制**（cross-attention），将条件信息注入到每层的去噪过程中。

具体而言，条件 $ c = (\hat{\mu}, \hat{\sigma}) $ 经过线性变换和卷积层映射为Key和Value向量，与图像特征的Query向量进行注意力计算。该机制使模型能够学习条件与图像特征之间的复杂非线性关系，从而在去噪过程中引导生成结果符合指定的条件。

训练目标是最小化预测噪声与真实噪声之间的均方误差（MSE），使用Adam优化器进行优化，并采用早停策略防止过拟合。扩散模型的去噪步数设为1000步，注意力头数为4，中间层通道数为20，以适应较小的输入尺寸。

### 3. 推理阶段

在推理阶段，模型根据用户指定的任意条件 $ c^* = (\hat{\mu}^*, \hat{\sigma}^*) $ 生成合成数据，无需依赖历史数据。

具体流程如下：
1. **条件输入**：用户指定目标趋势 $ \hat{\mu}^* $ 和目标已实现波动率 $ \hat{\sigma}^* $，经与训练阶段相同的变换处理，生成对应的Key和Value向量。
2. **图像生成**：将条件向量输入训练好的条件扩散模型，通过1000步反向扩散过程，从纯噪声中逐步去噪，生成一张与条件 $ c^* $ 对应的图像。
3. **序列重建**：对生成的图像应用**逆Haar小波变换**（inverse Haar wavelet transform），将其还原为一维对数收益率序列 $ \tilde{r}_t^* $。
4. **价格还原**：将标准化后的对数收益率序列 $ \tilde{r}_t^* $ 通过逆标准化还原为原始尺度，并累加恢复为价格序列 $ p_t^* $。

由于Haar小波变换是可逆的，该过程能精确地将图像空间的生成结果映射回时间序列空间，从而确保生成的金融时间序列在统计特性上严格符合用户指定的条件。

### 4. 核心创新点总结

- **条件控制机制**：首次在金融时间序列生成中，将趋势与已实现波动率作为显式条件，通过交叉注意力机制实现精确控制，突破了传统GAN仅依赖历史数据条件的局限。
- **小波图像转换**：利用Haar小波将一维时间序列转化为二维图像，使扩散模型能够有效建模长程依赖与局部波动结构。
- **高保真与高多样性**：模型在满足指定条件的同时，生成具有丰富多样性的序列，避免了GAN常见的模式崩溃（mode collapse）问题。
- **可扩展性**：条件设计具有通用性，可扩展至其他金融特征（如偏度、交易量等），为金融场景下的可控合成数据生成提供了新范式。

CoFinDiff通过上述架构，实现了对金融时间序列的“精准可控生成”——不仅能够复现金融数据的典型统计特征（如尖峰厚尾、波动聚集），还能按需生成极端事件（如暴涨暴跌、高波动）场景下的合成数据，为金融建模、压力测试与深度对冲等下游任务提供了高质量、可控制的训练数据源。
