# Financial Fine-tuning a Large Time Series Model

本文提出的方法是**对时间序列基础模型TimesFM进行金融数据的持续预训练（continual pre-training）以实现金融价格预测的微调**，具体方法包括以下四个核心组成部分：

---

### **1. 模型基础：TimesFM架构**

本文基于TimesFM（一种2亿参数的纯解码器（decoder-only）Transformer模型）进行微调。TimesFM的原始架构如下：
- **输入分块**：将输入时间序列划分为长度为 $ l_i = 32 $ 的补丁（patches）。
- **输出预测**：模型预测接下来 $ l_o = 128 $ 个时间点的值，满足 $ l_o > l_i $，以支持解码器模式并减少推理时的自回归步数。
- **训练目标**：使用均方误差（MSE）损失函数，对预测的 $ l_o $ 个输出点与真实值计算损失：
  $$
  \text{Train\_Loss} = \frac{1}{N} \sum_{j=1}^{N} \text{MSE}(\hat{y}_{l_i j + 1 : l_i j + l_o}, y_{l_i j + 1 : l_i j + l_o})
  $$
- **随机掩码**：在训练时，对输入序列的起始点和结束点进行随机采样，使模型能处理任意长度的上下文（最小上下文长度128，最大512），以增强泛化能力。
- **推理机制**：推理时不使用掩码，模型以自回归方式逐步生成未来点，每次生成 $ l_o = 128 $ 点，然后将生成点作为新输入继续预测。

---

### **2. 持续预训练策略**

本文不从头训练，而是**在TimesFM预训练权重基础上，使用金融价格数据进行持续预训练**：
- **初始化**：加载官方发布的TimesFM预训练权重。
- **优化器**：使用带动量（momentum=0.9）的SGD优化器。
- **学习率调度**：采用**线性热身（linear warmup）25个epoch**，随后使用**余弦退火（cosine decay）**，峰值学习率为 $ 5 \times 10^{-4} $。
- **训练时长**：在8块V100 GPU上训练约1小时，处理约8000万时间点（实际使用超1亿时间点）。
- **数据来源**：使用真实金融时间序列（无合成数据），涵盖股票（S&P500、TOPIX500）、外汇、加密货币、商品、指数等，粒度为**日频和小时频**，训练集截止至2022年底，2023年及以后数据用于测试。

---

### **3. 关键修改一：损失函数的对数变换**

原始MSE损失在金融价格数据上存在两大问题：
1. **尺度偏差**：高价值资产（如标普500指数，均价1000美元）主导损失，低价值资产（如加密货币，均价0.0001美元）被忽略。
2. **数值不稳定性**：价格崩盘（如跌幅>99%）导致梯度爆炸，产生NaN损失，训练崩溃。

**解决方案**：对原始价格序列进行**对数变换**：
$$
z = \log(y)
$$
- 模型输入为 $ z $，输出预测 $ \hat{z} $。
- 损失函数改为：
  $$
  \text{Train\_Loss} = \frac{1}{N} \sum_{j=1}^{N} \text{MSE}(\hat{z}_{l_i j + 1 : l_i j + l_o}, z_{l_i j + 1 : l_i j + l_o})
  $$
- **优势**：
  - 对数变换使损失等价于**百分比变化的MSE**，缓解尺度偏差。
  - 对大价格变动（如崩盘）的敏感度降低（log函数的“衰减”特性），显著提升训练稳定性，**全程无NaN损失**。

---

### **4. 关键修改二：适应金融数据的掩码策略**

为增强模型对金融时间序列的泛化能力，改进了原始掩码机制：
- **序列截断**：将长序列切分为最大长度为（最大上下文长度 + 输出长度）= 512 + 128 = 640的片段。
- **随机采样**：对每个训练样本：
  - 随机选择结束点 $ t_{\text{end}} \in [\text{min\_context\_len}, \text{max\_context\_len}] = [128, 512] $
  - 随机选择起始点 $ t_{\text{start}} \in [0, t_{\text{end}} - \text{min\_context\_len}] $
  - 输入为 $ [t_{\text{start}}, t_{\text{end}}] $ 的序列，预测其后 $ l_o = 128 $ 点。
- **目的**：
  - 确保模型能从任意长度（128–512）的上下文预测未来，适应金融数据的非平稳性和多尺度特性。
  - 每批次随机掩码防止过拟合，增强模型对局部模式的鲁棒性。
- **效果**：在1小时内完成8000万时间点训练，无NaN，训练稳定。

---

### **总结：方法核心**

本文提出的方法是：
> **在TimesFM的预训练权重基础上，通过“对数变换损失函数”和“自适应随机掩码策略”进行持续预训练，使模型适应金融价格数据的非平稳性、多尺度性和数值不稳定性，从而显著提升其价格预测能力。**

该方法不依赖外部文本信息、不使用合成数据、不进行重加权，仅通过架构适配和训练策略优化，实现金融时间序列的高效微调。
