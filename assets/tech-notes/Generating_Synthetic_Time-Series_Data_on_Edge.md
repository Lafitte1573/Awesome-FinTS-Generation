# Generating Synthetic Time-Series Data on Edge Devices Using Generative Adversarial Networks

本文提出了一种在边缘设备上利用生成对抗网络（GAN）生成合成时间序列数据的方法，其核心流程包括数据预处理、模型训练、模型优化和边缘部署四个阶段，具体方法如下：

1. **数据预处理**：  
   使用来自Yahoo Finance的金融时间序列数据集，包含Open、High、Low、Close、Adj Close和Volume六个属性，涵盖2017年1月1日至2021年1月24日共1,022个时间点的数据。数据无缺失值，确保完整性。所有特征通过MinMaxScaler进行归一化处理，将数值缩放到统一范围，以确保各特征对模型训练的贡献均衡。随后，数据按80:20的比例划分为训练集和测试集，用于模型训练与性能评估。

2. **模型架构设计（LSTM-GAN）**：  
   采用基于长短期记忆网络（LSTM）的生成对抗网络架构，其中生成器（Generator）和判别器（Discriminator）均以LSTM为核心组件。LSTM被选中是因为其能有效捕捉时间序列中的长期依赖关系，克服传统RNN的梯度消失/爆炸问题，通过门控机制（输入门、遗忘门、输出门）动态调节信息流，从而建模复杂的时序模式。生成器接收随机噪声向量 $ z \sim p_z(z) $（通常为高斯分布）作为输入，输出与真实时间序列具有相同维度的合成序列；判别器则接收真实数据或生成数据，输出一个概率值 $ D(x) $，表示该序列为真实数据的可能性。整个模型通过最小最大博弈优化，目标函数为：  
   $$
   \min_G \max_D V(D, G) = \mathbb{E}_{x \sim p_{data}(x)}[\log D(x)] + \mathbb{E}_{z \sim p_z(z)}[\log(1 - D(G(z)))]
   $$  
   训练过程采用交替梯度下降算法，迭代更新生成器和判别器参数，直至达到纳什均衡，使生成器输出的合成数据在统计特性上与真实数据高度相似。

3. **模型优化（面向边缘部署）**：  
   由于原始GAN模型参数量大、计算密集，不适用于资源受限的边缘设备，因此在模型训练完成后，对生成器进行轻量化优化，具体包括：  
   - **模型剪枝（Pruning）**：识别并移除对模型输出贡献较小的神经元、连接或层，减少冗余参数，降低模型复杂度。  
   - **模型量化（Quantization）**：将模型权重和中间激活值从32位浮点（float32）转换为16位浮点（float16），使模型体积减半，显著降低内存占用和存储需求。量化后通过小学习率对模型进行微调（fine-tuning），以补偿精度损失，确保生成质量不受显著影响。  
   优化后的模型仅保留生成器部分，因为边缘设备仅需执行数据生成（推理）任务，无需训练过程。

4. **边缘部署**：  
   将优化后的LSTM-GAN生成器部署于作者自主开发的边缘设备iBUG上。iBUG搭载双核ARM Cortex-M0+处理器（主频133 MHz）、246 KB SRAM和2 MB闪存，支持2.4 GHz IEEE 802.15.4无线通信，满足低功耗、低成本、高性能的边缘计算需求。部署后，设备可实时接收随机噪声输入，生成符合真实时间序列统计分布的合成数据，实现本地化、低延迟的数据合成能力。

该方法的创新性在于首次将LSTM-GAN架构成功适配并部署于资源受限的边缘设备，实现了从云端训练到边缘推理的端到端合成时间序列生成流程，为隐私保护、数据稀缺场景下的边缘智能应用（如实时异常检测、医疗诊断、工业监控等）提供了可行的技术路径。
