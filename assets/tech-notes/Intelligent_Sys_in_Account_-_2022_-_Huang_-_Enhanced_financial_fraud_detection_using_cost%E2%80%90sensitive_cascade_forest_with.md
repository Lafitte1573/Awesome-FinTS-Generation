# Enhanced financial fraud detection using cost-sensitive cascade forest with missing value imputation

本文提出的方法是**成本敏感级联森林（Cost-Sensitive Cascade Forest, CSCF）**，该方法是一种基于深度森林（Deep Forest）框架、专为财务报表欺诈检测设计的集成学习模型，其核心创新在于**引入成本敏感学习机制**并**自适应调整模型深度**，同时结合**缺失值零值填补策略**以提升预测性能。

### 1. 基础框架：级联森林（Cascade Forest, CF）

CSCF 基于 Zhou 和 Feng（2019）提出的深度森林（Deep Forest）架构，其核心是**级联森林（CF）结构**，该结构模仿深度神经网络的层叠处理机制，但完全基于决策树集成，避免了神经网络对大规模数据和超参数调优的依赖。

- **结构组成**：每一层由多个“基分类器”（base classifiers）组成，每个基分类器是一个由多个决策树构成的随机森林（RF）或完全随机森林（Extra-Trees）。
- **输入处理**：第一层仅使用原始特征作为输入；后续每一层的输入是前一层输出的预测概率（或特征表示）与原始输入特征的**级联拼接**（concatenation），实现逐层特征变换。
- **自适应深度**：模型通过逐层添加新层并计算性能增益（如准确率）来自动决定停止条件。当新增一层不再带来显著性能提升时，训练终止，无需人工设定层数。
- **超参数少**：仅需调节两个超参数：每层的森林数量（estimators per layer）和每棵森林中的树数量（trees per estimator），具有良好的鲁棒性和泛化能力。
- **防止过拟合**：每一层的基分类器均采用 K 折交叉验证进行训练，以降低过拟合风险。

### 2. 核心改进：成本敏感机制（Cost-Sensitive Learning）

财务欺诈检测中，**假阴性（Type II 错误，漏报欺诈）的成本远高于假阳性（Type I 错误，误报非欺诈）**，因此传统以准确率为目标的模型不适用。CSCF 引入成本敏感学习，通过以下方式优化：

- **类别权重调整**：在每个基分类器的**自助采样（bootstrap sampling）**过程中，为少数类（欺诈样本）分配更高的权重，使模型在训练时更关注欺诈样本的识别。
- **权重计算公式**：对于每个自助样本中的类别 $i$，其权重为：
  $$
  w_i = \frac{n_{samples}}{n_{classes} \times n_{sample_i}}
  $$
  其中 $n_{samples}$ 为该样本中总观测数，$n_{classes} = 2$（欺诈/非欺诈），$n_{sample_i}$ 为类别 $i$ 在该样本中的观测数。该权重与类别频率成反比，确保少数类获得更高惩罚权重。
- **实现方式**：在 Python 的 `CascadeForestClassifier` 中，通过设置 `class_weight="balanced_subsample"` 参数实现该机制。

### 3. 关键优化：以召回率（Recall）为停止准则

传统深度森林以**准确率（Accuracy）**作为层数增长的停止标准，但欺诈检测中，**召回率（Sensitivity）**才是关键指标，因为漏报欺诈的代价极高。

- **修改停止条件**：CSCF 将层增长的终止标准从“准确率提升”改为“**召回率提升**”。
- **机制效果**：模型持续添加新层，直到新增层无法显著提升对欺诈样本的召回率为止。这确保了模型在最终结构中优先优化对欺诈案例的识别能力，而非整体准确率。
- **性能导向**：该设计使 CSCF 在预测排名（如 Top 1% 高风险公司）中表现显著优于传统模型，尤其在高不平衡数据下更有效。

### 4. 缺失值处理：零值填补（Zero Imputation）

由于财务数据普遍存在缺失值，CSCF 与多种缺失值处理方法对比后发现：

- **零值填补最优**：在所有测试方法（完整案例分析、均值、修正均值、KNN、随机森林插补）中，**将缺失值统一替换为 0** 时，CSCF 表现最佳。
- **原因分析**：财务变量（如资产、收入）的缺失通常意味着该指标未报告或为零（如未披露的费用），零值填补在财务语境下具有合理经济含义，且能保留样本信息，避免完整案例分析导致的样本量骤减和偏差。
- **性能提升**：采用零值填补后，CSCF 的 AUC 达到 **0.82**（2003–2005 年测试期），远超基线模型 RUSBoost 的最高 AUC（0.71），且在 NDCG、召回率@1%、F2@1% 等排名指标上提升显著（最高提升超 4 倍）。

### 5. 整体流程总结

1. **数据预处理**：使用原始财务变量（非比率），剔除缺失值超过 25% 的观测，其余缺失值统一用 0 填补。
2. **模型构建**：构建级联森林结构，每层包含两个随机森林和两个完全随机森林（共 4 个基分类器），每森林含 100 棵树。
3. **成本敏感训练**：在每个基分类器的自助采样中，应用“balanced_subsample”权重机制，提高欺诈样本的误分类惩罚。
4. **自适应深度**：每新增一层，计算召回率提升；当连续层无显著召回率提升时停止训练。
5. **预测与评估**：使用 K 折交叉验证减少过拟合，评估指标以 AUC、NDCG、Recall@1%、F2@1% 为主，聚焦欺诈识别的排序能力。

### 结论

本文提出的 **CSCF** 是一种**专为财务欺诈检测设计的、成本敏感的、自适应深度的级联森林模型**，其核心贡献在于：

- 将**成本敏感学习**嵌入深度森林的训练过程，通过样本加权强化对欺诈类别的识别；
- 以**召回率**为模型深度的自适应停止标准，确保模型优化目标与欺诈检测的业务需求一致；
- 通过**零值填补**处理缺失数据，在保留样本信息的同时显著提升模型性能；
- 实证表明，CSCF 在 AUC、NDCG 和 Top 1% 预测精度上全面超越 RUSBoost 等当前先进模型，是财务欺诈检测领域一项高效、鲁棒、实用的创新方法。
