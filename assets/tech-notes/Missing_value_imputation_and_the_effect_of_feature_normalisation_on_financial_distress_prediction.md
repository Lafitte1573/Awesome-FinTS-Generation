# Missing value imputation and the effect of feature normalisation on financial distress prediction

本文提出的方法围绕两个核心研究目标展开：（1）比较多种深度学习与传统机器学习方法在金融困境预测数据集上的缺失值填补性能；（2）探究特征归一化（feature normalisation）在缺失值填补后对分类模型性能的影响。具体方法步骤如下：

1. **数据集准备与预处理**：
   - 使用九个金融困境相关数据集（四个破产预测数据集、五个信用评分数据集），涵盖不同特征数量（9–95）、样本数量（152–150,000）和类不平衡比例（1–30）。
   - 对除JPNBDS和USABDS外的所有数据集应用SMOTE（Synthetic Minority Oversampling Technique）算法，使训练集中的多数类（非破产/良好信用）与少数类（破产/不良信用）样本数量相等，以缓解类别不平衡问题。

2. **缺失值模拟**：
   - 在平衡后的训练集和测试集上，依据“完全随机缺失”（MCAR）机制，人为模拟五种缺失率：10%、20%、30%、40%、50%，以系统评估不同缺失程度下各填补方法的性能。

3. **缺失值填补方法**：
   - 采用四种填补算法进行比较：
     - **KNN（k-最近邻）**：基于欧氏距离寻找最相似样本，用其观测值填补缺失值。
     - **MICE（多重插补链式方程）**：通过一系列回归模型（如线性回归、逻辑回归）迭代生成多重填补值。
     - **RF（随机森林）**：利用集成决策树模型，通过构建回归树预测缺失特征值，最终综合所有树的预测结果作为填补值。
     - **DNN（深度神经网络）**：构建一个全连接神经网络，输入含缺失值的特征向量，输出填补后的完整特征向量，网络结构为两层隐藏层（每层100个神经元），激活函数为ReLU，使用Adam优化器训练。
   - 同时设置“基线方法”（Baseline）：对连续变量用均值填补，对离散变量用众数填补，作为性能对比基准。

4. **特征归一化**：
   - 在缺失值填补完成后，对训练集和测试集分别应用**最小-最大归一化**（Min-Max Normalization）：
     $$
     x' = \frac{x - \min(x)}{\max(x) - \min(x)}
     $$
   - 归一化参数（最小值与最大值）仅从训练集计算得出，并应用于测试集，以避免数据泄露。

5. **分类模型构建与评估**：
   - 对每种填补方法（含基线）及其与归一化的组合，分别训练三种分类器：
     - **SVM（支持向量机）**：使用RBF核函数。
     - **RF（随机森林）**：100棵树，基尼不纯度作为分裂标准。
     - **DNN（深度神经网络）**：结构与填补用DNN相同（两层100神经元，ReLU，Adam，学习率0.01，100轮训练，早停机制）。
   - 所有实验采用5折交叉验证，确保结果稳健性。

6. **性能评估指标**：
   - 使用**AUC（受试者工作特征曲线下面积）**衡量整体分类性能，反映模型区分破产与非破产样本的能力。
   - 使用**II类错误率（Type II Error）**衡量漏报率，即实际破产但被预测为非破产的样本比例，这对金融机构控制坏账风险至关重要：
     $$
     \text{Type II} = \frac{FN}{TP + FN}
     $$

7. **实验设计对比**：
   - 设置两组对比实验：
     - **仅填补组**：仅使用填补后数据训练分类器，不进行归一化。
     - **填补+归一化组**：在填补后对特征进行归一化，再训练分类器。
   - 通过比较两组在AUC和II类错误上的差异，评估归一化对最终预测性能的影响。

8. **关键分析点**：
   - 分析不同填补方法在不同缺失率下的性能变化趋势。
   - 分析不同分类器对填补结果的敏感性（即分类器性能是否依赖于输入特征的尺度）。
   - 判断归一化是否对所有分类器都带来提升，或仅对特定分类器有效。

综上，本文方法系统性地评估了“填补算法 × 归一化策略 × 分类器选择”三者组合对金融困境预测性能的影响，旨在为实际应用提供最优的预处理流程建议。
