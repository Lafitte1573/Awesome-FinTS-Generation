# StockTime: A Time Series Specialized Large Language Model Architecture for Stock Price Prediction

本文提出的StockTime是一种专为股票价格预测设计的大型语言模型（LLM）架构，其核心思想是将股票价格时间序列数据直接作为LLM的输入令牌（tokens），并利用LLM固有的下一个令牌预测能力进行未来价格的自回归预测，同时通过从价格数据中提取并融合文本信息增强模型对时间序列内在结构的理解，而无需依赖外部文本数据或对LLM主干进行微调。

具体方法步骤如下：

1. **分块输入（Patched Input）**  
   首先，对原始股票价格序列进行标准化处理（均值为0、标准差为1），采用可逆实例归一化以保留原始尺度信息。随后，将标准化后的股票价格序列分割为一系列不重叠的连续“补丁”（patches），每个补丁长度为 $ l $，包含 $ l $ 个连续的价格点。每个补丁被视为一个基本的“令牌”（token），从而将连续的时间序列转化为一个离散的令牌序列 $ \{ \mathbf{h}_1, \mathbf{h}_2, ..., \mathbf{h}_n \} $，其中 $ n $ 为补丁总数。这种分块策略显著降低了输入序列的长度，从而降低计算负担。

2. **自回归编码器（Autoregressive Encoder）**  
   为有效捕捉股票价格序列中的长期时序依赖关系，设计了一个基于LSTM的自回归编码器。该编码器接收每个价格补丁 $ \mathbf{h}_i $ 作为输入，通过LSTM层逐时间步处理，学习其隐含的时序动态特征。LSTM的输出通过一个全连接层投影到LLM的潜在维度 $ d_{\text{llm}} $，生成价格嵌入 $ \mathbf{pe}_i \in \mathbb{R}^{1 \times d_{\text{llm}}} $。该编码器的作用是将原始价格补丁转化为适合LLM处理的语义嵌入，同时保留时间序列的顺序依赖性。

3. **多模态融合（Multimodal Fusion）**  
   为增强LLM对价格序列中隐含结构的理解，StockTime从同一价格数据中自动生成文本信息，而非依赖外部新闻或社交媒体文本。该文本信息包含三个关键成分：  
   - 时间序列频率（如日频、小时频）；  
   - 股票所属行业分类；  
   - 统计特征（每个补丁的最小值、最大值、均值、平均变化率及对应的时间戳）。  
   这些信息被格式化为自然语言模板（如“该补丁为科技行业股票，价格区间为[120.5, 125.3]，平均日变化率为+1.2%，时间戳为2024-07-10”），并通过一个冻结的LLM（如LLaMA3）进行编码，生成对应的文本嵌入 $ \mathbf{ce}_i \in \mathbb{R}^{1 \times d_{\text{llm}}} $。随后，将价格嵌入 $ \mathbf{pe}_i $ 与文本嵌入 $ \mathbf{ce}_i $ 在潜在空间中进行逐元素相加融合，得到联合嵌入 $ \mathbf{e}_i = \mathbf{pe}_i + \mathbf{ce}_i $。此融合机制使LLM在不增加上下文长度的前提下，同时感知数值序列和其衍生的语义线索（如趋势、相关性、行业背景），从而提升预测的语义一致性。

4. **令牌级预测（Token-level Prediction）**  
   融合后的嵌入序列 $ \{ \mathbf{e}_1, \mathbf{e}_2, ..., \mathbf{e}_n \} $ 被输入一个冻结的预训练LLM（如LLaMA3-8B）中，LLM利用其自注意力机制和自回归生成能力，预测下一个补丁令牌 $ \hat{\mathbf{h}}_{i+1} $。训练目标是让模型预测的下一个补丁 $ \hat{\mathbf{h}}_{i} $ 尽可能接近真实补丁 $ \mathbf{h}_i $，即最小化从第2个补丁到第 $ n+1 $ 个补丁的均方误差（MSE）损失：  
   $$
   \text{MSE} = \frac{1}{nl} \sum_{i=2}^{n} \| \hat{\mathbf{h}}_i - \mathbf{h}_i \|_2^2
   $$  
   仅训练嵌入层（将原始补丁映射到LLM维度）和投影层（将LLM输出映射回价格补丁维度），而冻结LLM主干参数，从而大幅降低训练成本和内存占用。预测时，模型通过自回归方式逐块生成未来 $ x $ 天的股票价格，突破传统模型对固定预测窗口的限制。

综上，StockTime通过将股票价格转化为令牌序列，结合自回归编码器提取时序特征，再融合由价格数据自生成的语义文本信息，最终利用冻结LLM的自回归预测能力实现高效、准确、无外部文本依赖的股票价格预测。其创新在于完全基于价格数据自身构建多模态输入，避免了FinLLMs对低质量文本数据的依赖，同时保持了LLM的长序列建模能力与灵活性。
