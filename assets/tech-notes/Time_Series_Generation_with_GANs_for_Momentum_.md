# Time Series Generation with GANs for Momentum Effect Simulation on Moscow Stock Exchange

本文提出了一种基于时间卷积网络（Temporal Convolutional Network, TCN）的生成对抗网络（GAN）架构，用于生成多维金融时间序列，以模拟莫斯科证券交易所股票的对数收益率，并评估动量效应（Momentum Effect）。

方法的核心包括以下关键组成部分：

1. **架构设计**：  
   生成器（Generator）与判别器（Discriminator）均采用相同的TCN结构。TCN通过膨胀卷积（dilated convolutions）有效捕捉长时序依赖，克服了传统RNN在长序列训练中的梯度消失问题。每一层使用核大小为2的卷积，膨胀率依次为1、2、4、8，使感受野呈指数级增长，从而建模长达126个时间步的依赖关系。输入窗口固定为126，即每次输入一个连续的126天收益率序列。

2. **输入噪声与输出控制**：  
   生成器的输入噪声维度为15（3倍于5只股票的数量），即每个时间步输入3维随机噪声向量，共126×15个随机值。噪声通过滑动窗口机制连续输入，确保相邻时间步的生成序列具有时间连续性，避免未来信息泄露，从而模拟真实金融序列的动态依赖结构。

3. **网络结构细节**：  
   - 输入首先通过一个1×1卷积层将噪声维度映射到隐藏通道数（最多10维）；  
   - 接着是四个膨胀卷积层，每层后接ReLU激活函数；  
   - 每层输出通过“跳跃连接”（skip connections）进行残差求和，以增强梯度传播与特征复用；  
   - 生成器最后一层输出维度调整为5（对应5只股票的收益率）；  
   - 判别器最后一层输出为单维，通过线性层和Sigmoid激活函数输出真实/伪造概率。

4. **训练策略**：  
   - 使用RMSprop优化器，学习率为0.0002，批量大小为256；  
   - 为稳定训练，对判别器权重进行[-0.01, 0.01]的裁剪（WGAN风格）；  
   - 采用“交替训练”策略：每批次训练判别器，每两批次训练一次生成器，以防止判别器过强导致生成器梯度消失；  
   - 训练800个epoch，使用NVIDIA GeForce GTX 1650 Ti GPU，耗时约5–10分钟。

5. **数据后处理**：  
   生成的收益率序列经过标准化处理，使其均值与标准差与真实历史数据完全一致，确保生成数据在统计特征上与真实数据匹配，仅模拟序列内部的动态依赖结构，而非改变边缘分布。

6. **目标与应用**：  
   该方法旨在生成具有真实金融时间序列统计特性（如波动聚集、跨资产相关性）的合成数据，用于动量策略的回测与超参数调优。特别地，通过对比真实数据与合成数据在动量策略表现上的差异，评估GAN是否成功捕获了动量效应这一弱但重要的非线性时序模式。

该方法通过TCN-GAN架构，实现了对多维金融时间序列中复杂时空依赖关系的建模，其核心创新在于将TCN用于GAN的生成与判别结构，并通过滑动噪声窗口与权重裁剪策略提升训练稳定性，最终目标是为策略开发提供高保真、可扩展的合成市场环境。
