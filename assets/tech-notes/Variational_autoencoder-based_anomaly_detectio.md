# Variational autoencoder-based anomaly detection in time series data for inventory record inaccuracy

本文提出了一种基于变分自编码器（Variational Autoencoder, VAE）的无监督时间序列异常检测方法，用于识别零售业库存记录不准确性（Inventory Record Inaccuracy, IRI）。该方法针对库存数据的时间依赖性、多维度性和动态变化特性，构建了一个可扩展、自适应的检测框架，适用于单变量和多变量时间序列场景。具体方法步骤如下：

1. **数据收集与产品层级构建**：  
   从土耳其一家大型超市连锁企业的大数据平台（使用PySpark）获取每日库存数据。依据产品层级结构（主类→子类→品牌），将库存数据聚合至“子类别”（subcategories）层级。例如，“巴氏杀菌奶”和“有机奶”属于“奶制品&酸奶”大类下的不同子类别。根据业务需求，可选择单个子类别构建单变量时间序列，或同时纳入多个子类别构建多变量时间序列。

2. **特征工程**：  
   为每个时间点构造反映库存动态的特征：  
   - **库存状态特征**：当前库存量（Tt）、前一日百分比变化（Tpctchange）、过去7日平均值（Tavglast7）、过去7日标准差（Tstdlast7）、过去7日变异系数（ICVlast7）。  
   - **时间周期特征**：为捕捉季节性模式，采用正弦-余弦编码（sin-cos encoding）表示日期、周、月的循环特性，将365天的日期信息压缩为两个连续变量（sin(2π·day/365), cos(2π·day/365)），避免独热编码导致的维度爆炸，同时保持时间点的周期邻近性（如1月1日与12月31日在嵌入空间中接近）。

3. **数据预处理**：  
   - **缺失与负值处理**：系统错误导致的缺失值和因退货超过销售导致的负库存值均被替换为0。  
   - **极端值处理**：采用改进的Tukey IQR方法（3×IQR而非1.5×IQR）识别极端值，以避免误删潜在异常；极端值被替换为NaN，再通过线性插值填补，保留数据趋势。  
   - **归一化**：对所有特征进行逐特征最小-最大归一化（min-max normalization），使所有变量缩放至[0,1]区间，消除量纲影响。

4. **变分自编码器（VAE）模型构建**：  
   - **模型结构**：  
     - **单变量模型**：输入层11维（10个特征+1个库存量），编码器为11→20→3神经元，解码器为3→20→11神经元，隐变量z维度为3，服从高斯分布。  
     - **多变量模型**：输入层18维（18个子类别的库存量），编码器为18→25→5神经元，解码器为5→25→18神经元，隐变量z维度为5。  
   - **训练机制**：  
     - 使用Keras实现，批量大小为32，训练250轮（单变量）或500轮（多变量）。  
     - 损失函数为均方误差（MSE），优化目标为最大化证据下界（ELBO），即最小化重构误差与KL散度之和。  
     - 编码器输出隐变量z的均值μ和标准差σ，采样z ∼ N(μ, σ²I)，解码器重建输入x̂。  
   - **动态建模能力**：VAE通过学习潜在空间的概率分布（而非单一映射），能适应消费者行为和销售策略的时变特性。

5. **异常检测与报警生成**：  
   - **异常定义**：异常由重构误差衡量。对每个样本，计算每个特征的绝对重构误差（|x_i - x̂_i|）和总异常得分（各特征误差的加权或聚合）。  
   - **阈值设定**：对每个特征的异常得分，采用Q3 + 1.5×IQR作为动态阈值，自动适应数据分布变化。  
   - **异常判定**：若某日的总异常得分超过阈值，或任一关键特征（如库存量、百分比变化）的误差超过其独立阈值，则标记为异常。  
   - **输出优势**：VAE可分别分析每个特征的异常贡献（如高库存、突降、波动加剧），而非仅输出单一综合分数，便于业务人员定位根本原因（如误发货、漏补货）。

6. **双模式支持**：  
   - **单变量模式**：独立建模单个子类别，适用于关注易腐品或高价值单品的场景。  
   - **多变量模式**：联合建模多个子类别，捕捉类别间交互异常（如用普通奶替代巴氏奶导致的库存错配），适用于整体品类协同管理。

7. **模型评估与对比**：  
   与孤立森林（Isolation Forest）对比，VAE在单变量场景下显著减少误报（27 vs 146个异常），且能区分高/低库存异常，而孤立森林仅识别高值异常。多变量模式下，VAE可为每个子类别独立计算重构损失，实现细粒度异常定位。

综上，本文方法通过VAE建模库存数据的潜在概率分布，结合时间周期编码与动态阈值机制，实现了无需人工标注、可扩展、细粒度的库存异常检测，为零售企业提供了实时预警与根因分析能力。
