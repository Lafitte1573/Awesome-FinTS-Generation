# Article

本文提出的**连接增强（Concatenation Augmentation, CA）**是一种专为金融领域自然语言处理（NLP）中**数据稀缺**场景设计的新型数据增强技术，其核心思想是通过**文本连接**与**标签凸加性运算**生成新的训练样本，在保持语义连贯性的同时显著提升深度学习模型的泛化能力。

### 方法核心机制

CA 方法基于以下两个关键操作：

1. **输入连接（Concatenation）**  
   对于训练集中任意两个样本 $(x_i, y_i)$ 和 $(x_j, y_j)$，其中 $x_i, x_j$ 为文本序列（如独立董事的履历文本），CA 通过简单的**字符串连接操作** $\oplus$ 生成新的输入样本：
   $$
   \tilde{x} = x_i \oplus x_j
   $$
   在实现中，仅对缺失句末标点的文本添加终止符（如句号），**不进行任何词法或句法修改**（如替换、翻译、 paraphrasing），确保原始语义信息完整保留。这种连接方式直接利用了文本的**序列特性**，避免了在词嵌入空间进行插值（如 WMix）可能破坏语义结构的问题。

2. **标签凸加性组合（Convex Additive Label Combination）**  
   新样本的标签 $\tilde{y}$ 不是简单平均，而是通过一个**基于激活函数逆变换的凸加性函数 $\Phi$** 计算：
   $$
   \tilde{y} = \Phi(y_i, y_j) = \sigma\left( \sigma^{-1}(y_i) + \sigma^{-1}(y_j) \right)
   $$
   其中：
   - $\sigma(y) = \frac{1}{1 + e^{-y}}$ 是逻辑（Sigmoid）激活函数；
   - $\sigma^{-1}(y) = \ln\left(\frac{y}{1 - y}\right)$ 是其逆函数（logit 变换）。

   该函数的数学本质是：**将概率标签映射到对数几率空间进行线性相加，再映射回概率空间**。这一操作隐含了“知识叠加”的先验假设：两个专家的履历所体现的能力维度（如金融、学术）若独立存在，则其综合能力可视为在对数几率空间中的加和。

   具体展开形式为：
   $$
   \Phi(y_i, y_j) = \frac{y_i y_j}{1 - y_i(1 - y_j) - y_j(1 - y_i)}
   $$

   此设计保证了：
   - 输出仍在 $[0, 1]$ 区间内；
   - 当 $y_i = y_j = 0.5$ 时，$\tilde{y} = 0.75$，体现“叠加增强”；
   - 当任一标签为 0 时，$\tilde{y} = 0$，体现“短板效应”；
   - 当任一标签为 1 时，$\tilde{y} = 1$，体现“主导效应”。

### 方法设计动机

- **继承 LSR 与 Mixup 的优点**：  
  - 类似 **Label Smoothing Regularization (LSR)**，CA 通过引入标签扰动防止模型过拟合，但其扰动源于真实数据组合，而非均匀分布注入，更具语义依据。  
  - 类似 **Mixup**，CA 通过线性组合增强数据多样性，但将图像空间的像素插值转化为文本空间的**语义连接 + 对数几率加法**，解决了 NLP 中无法直接插值变长序列的根本难题。

- **规避现有方法缺陷**：  
  - 相比 **WMix**（词嵌入插值），CA 不依赖模型内部结构，无需修改网络代码，可直接在数据预处理阶段实现；  
  - 相比 **LLM 生成**（如 ChatGPT），CA 无需外部模型、无生成偏差、无高计算成本、无语义漂移风险；  
  - 相比 **同义词替换、翻译回译**，CA 不引入语义失真或语法错误，完全基于原始文本组合。

### 方法优势总结

1. **语义与空间一致性**：连接操作保留原始文本结构，加性标签函数符合能力叠加的现实逻辑；
2. **极低计算成本**：仅需字符串拼接与简单数学运算，无复杂模型调用或嵌入计算；
3. **无超参数依赖**：无需调整 $\alpha$、$\lambda$ 等参数，直接使用默认设置即有效；
4. **模型无关性**：可无缝集成于任意 NLP 模型（如 LSTM、Transformer）的输入层，不修改网络结构；
5. **可自动化**：完全可编程，适合大规模训练流水线；
6. **适用于回归任务**：专为多维连续标签（0.0–1.0，步长0.1）设计，契合金融专家评分场景。

### 应用场景

CA 专为**金融文本分析中的小样本回归任务**优化，尤其适用于：
- 董事会成员履历中的多维能力评分（金融、法律、学术等）；
- 企业治理报告中非结构化文本的隐含信息提取；
- 任何标签为概率型连续值、且文本具有语义可组合性（如专家经验叠加）的 NLP 任务。

综上，**Concatenation Augmentation (CA)** 是一种简洁、高效、语义合理且工程友好的数据增强方法，通过“文本连接 + 对数几率加法”实现了在数据稀缺条件下对深度学习模型性能的显著提升。
