# LLM40FD: Unlocking the Potential of LLM for Anonymous Zero-Shot Fraud Detection

Kaixiang Yang $\textcircled { 1 0 }$ , Member, IEEE, Zhijie Zhong $\textcircled{1}$ , Song Sun $\textcircled { 1 0 }$ , Zhiwen Yu $\circledcirc$ , Senior Member, IEEE, C. L. Philip Chen $\textcircled{1}$ , Life Fellow, IEEE, and Tong Zhang $\textcircled { 1 0 }$ , Senior Member, IEEE

Abstract—Credit card (CC) fraud detection within the realm of financial security faces challenges such as data imbalance, largescale anonymized transaction datasets, and the need for systemspecific model training. Past methods often fail to address these aforementioned issues simultaneously. Utilizing a single model results in a lack of zero-shot capability without adaptation for real-world scenarios. This article introduces LLM40FD, a novel framework that leverages a large language model (LLM) to overcome these obstacles in anonymous zero-shot fraud detection. LLM40FD addresses the aforementioned challenges in CC fraud detection by employing a distribution-based one-class function and the walking embedding, without reliance on labeled data or fine-tuning in downstream. Additionally, LLM40FD enhances the model’s ability to detect fraudulent patterns and define robust decision boundaries. This is achieved through a dualaugmentation strategy and implicit contrastive learning, which generate enriched positive and negative samples. Our experiments demonstrate that LLM40FD not only achieves state-ofthe-art (SOTA) performance in the full-shot setting but also exhibits strong zero-shot capability even with limited training data. Furthermore, we conduct additional experiments to validate the effectiveness and working mechanism of LLM40FD.

Index Terms—Data augmentation, fraud detection, large language model (LLM), zero-shot.

# I. INTRODUCTION

C REDIT card (CC) fraud is a form of financial fraud thatinvolves the illegal acquisition of cardholder information through deception, misrepresentation, and identity falsification, resulting in the theft of CC funds [1], [2], [3].

Banks and other financial institutions often develop fraud detection models that utilize the CC spending history of customers to mitigate the risks and losses associated with CC fraud. In recent years, many researchers have explored the application of machine learning and deep learning techniques for studying CC fraud detection [4]. These techniques include supervised [5], [6], [7], unsupervised [7], [8], [9], and semisupervised methods [7], [8]. Supervised and semisupervised methods rely on labeled data to train the model, with transactions generated by cardholders classified as genuine and those generated by fraudsters classified as fraudulent. However, obtaining label information in a timely manner is challenging in practice [4].

Previous researchers have employed unsupervised anomaly detection algorithms, including K-nearest neighbors (KNN), K-means, and isolation forest (IForest) [10], [11], for CC fraud detection and have achieved promising results [12]. Furthermore, some researchers have incorporated unsupervised techniques to address CC fraud. For instance, Lepoivre et al. [13] combined principal component analysis (PCA) and K-means to classify transactions, using K-means to cluster samples after the initial transaction data were processed with PCA. However, this approach is prone to converging on local optima and requires multiple algorithm iterations. Recently, deep learning methods have emerged as powerful tools for various detection tasks. In Section II-A, we provide a detailed explanation for these methods.

However, these methods fall short in addressing three significant challenges.

1) Challenge 1: The scarcity of labels and insufficient samples of fraudulent behavior in CC fraud detection.   
2) Challenge 2: The volume of CC transaction data is large, and CC transaction data may be anonymized, making it difficult for traditional models to effectively utilize all the data and comprehend the features. Anonymous features can be regarded as those where the model lacks knowledge of the specific meaning of each feature. Moreover, perhaps due to security reasons, the original features may have been dimensionally reduced, making it impossible to know their original meanings. For example, in Fig. 2,

# II. RELATED WORK

# A. CC Fraud Detection

The methodology presented by [14] uses deep autoencoders (AEs) and three methods: one-class classification, reconstruction scores, and generative adversarial networks. These techniques contribute to the development of more interpretable models for CC fraud detection. Another hybrid unsupervised learning approach introduced by [15] combines particle swarm optimization (PSO) with K-means clustering to enhance the performance of CC fraud detection. Singh and Jain [16] proposed enhancing machine learning through feature-selection methods, which improved the performance of the original random forest and AdaBoost in fraud detection. The multidimensional similarity space [17] utilizes three predefined different similarity metrics to better distinguish between fraud and normal behavior. Both of these methods are traditional fraud detection methods based on hand designed features.

Additionally, WMTDBC [18] presents an innovative unsupervised multivariate analysis model that constructs a weighted multitree (WMT) and applies density-based clustering (DBC) techniques to detect fraud. Furthermore, Zheng et al. [5] propose a fraud detection method that utilizes a logical graph of behavior profiles (LGBPs) to enhance the representation of user transaction behaviors, offering a diversified approach compared to traditional Markov chain models. Lastly, TrAdaBoost [19] introduces an algorithm that improves CC fraud detection by adapting to subtle distribution changes through RKHS-based distribution distance calculation. AdaTrans [20] recently proposed applying the advanced transformer architecture to the fraud detection space. It is the SOTA approach in this field because of its exceptional performance. Despite its strong performance in a single data source, its lack of zero-shot capabilities prevents it from being widely used.

Despite the widespread application of unsupervised methods in CC fraud detection, they face significant challenges in effectively addressing the issue of large-scale anonymized transaction data. Furthermore, and of greater significance, these models lack the ability to achieve zero-shot capability, which significantly restricts their utility.

# B. LLM

The LLM is a generative language model constructed using the attention mechanism, enabling it to undertake sophisticated tasks such as question answering and reasoning [21]. For example, ChatGPT is one of the most notable models in this domain [22]. LLMs possess strong transfer learning capabilities, allowing them to transfer knowledge acquired from text to different modalities, including images, videos [23], time series, texts [24], and tabular data [25], [26]. ModaVerse [27] is an example of a multimodal LLM (MLLM) that can understand and transform content from various modalities, such as images, videos, and audio. In the realm of time series data, the LLM4TS framework proposed by [28] leverages pretrained LLMs for transfer learning to effectively handle limited nonlinguistic datasets for time series prediction.

Regarding tabular data, Liu et al. [29] investigate the capabilities of LLMs in interpreting and reasoning with tabular data. They propose a dialogue-based approach to generate textually unified structures for tables. Meanwhile, they found that changes in the structure of tabular data can significantly impact model performance. Furthermore, Bakumenko et al. [30] propose a novel paradigm for representing tabular data by transforming it into text to achieve a unified tabular data representation. Korkanti [31] proposed fine-tuning LLM for fraud detection and combining them with IForest and logistic regression to detect fraud. However, this approach does not make better use of the pretrained knowledge of LLM, cannot achieve zero-shot learning, and requires additional fine-tuning of LLM, thus demanding more computational resources.

Although LLMs for tabular data possess the capability to convert text into unified embeddings, they may struggle to adequately capture feature representations when dealing with anonymized CC transaction data. This limitation arises from the fact that anonymous features cannot be directly and meaningfully represented in text.

# C. Zero-Shot

Zero-shot learning pertains to the capacity of a model to classify or recognize classes that have not been encountered previously, in the absence of specific samples from those classes [32], [33], [34]. Furthermore, this often necessitates that the model perform well even in scenarios with diverse distributions. This learning paradigm has found widespread applications across various domains [33], [35], including social media [34], [36].

For instance, Buchelnikov et al. [37] explore how transferable semantic knowledge can be utilized for zero-shot learning in text classification tasks. Sun et al. [38] investigate the application of zero-shot learning in medical image analysis, particularly in scenarios where no annotated data is available. Additionally, Albergo et al. [39] propose a novel zero-shot recommendation system approach to address the cold-start problem in recommender systems.

By reducing the dependence on large amounts of annotated data, particularly for difficult-to-obtain data such as fraud cases, zero-shot learning presents the potential to rapidly adapt to new tasks without requiring additional training. Therefore, we incorporate this concept into CC fraud detection to address Challenge 3.

# III. PROPOSED APPROACH

# A. Problem Definition

For the given transaction data $X \in \mathbb { R } ^ { N \times d }$ , where $N$ represents the number of samples in the transactions, each transaction data $x _ { i }$ has a corresponding label $y _ { i }$ indicating whether it is a fraudulent behavior. A label of $y _ { i } = 1$ signifies a fraudulent transaction. In an unsupervised setting, the model leverages transaction data without labels to acquire the knowledge of detecting fraud.

In the case of full-shot or subset training, the model uses all or a part of the training data $X _ { \mathrm { { t r a i n } } }$ to infer whether a transaction is fraudulent on test data $X _ { \mathrm { t e s t } }$ that is drawn from the same distribution. However, in the case of zero-shot learning, the inference is performed using transaction data $X _ { \mathrm { t e s t } } ^ { \prime }$ that is different from the training data $X _ { \mathrm { t r a i n } }$ , coming from a different distribution. In other words, the training data may come from Bank A, while the inference data comes from Bank B or other transaction systems.

# B. Overview

Fig. 2 illustrates the model architecture and key components of LLM40FD, along with its workflow. These components include. 1) Walking Embedding: This component consists of a series of embeddings that transform transaction data into tokens that can be understood by the LLM. 2) Knowledge Center: The knowledge center serves as a mechanism for knowledge distillation by establishing a central distribution of nonfraudulent behaviors. 3) Dual-Augmentation: This component encompasses techniques that enhance both positive and negative samples, enabling the model to learn more distinct decision boundaries.

Our approach does not involve fine-tuning any parameters of the LLM, but instead focuses on training walking embeddings to characterize anonymous features.

# C. Unified Representation

The anonymization process applied to transactional data often results in the loss of original textual semantic information, thereby posing a significant challenge for LLMs to comprehend the data. To address this issue, we propose utilizing walking embedding as a substitute for the LLM’s original token embeddings in order to construct a unified representation.

We integrate various features to form a token, enabling the LLM to “walk” across the features with a specific stride. This approach not only facilitates the LLM’s comprehension of the data in a tokenized manner but also reduces computational complexity by embedding different features as multiple tokens. This enhancement in computational efficiency improves both the inference speed and the practical usability of LLMs in fraud detection scenarios.

Walking embedding differs from previous embeddings in the following aspects. 1) The embeddings used by LLMs convert text (tokens) into text representations [40]. However, in the scenario of anonymous fraud detection without text, they cannot be directly applied. 2) Typically, in the scenario of tabular data, an MLP is used as a feature extractor to generate an embedding [29], [30]. Nevertheless, due to the fixed dimensionality of the MLP, this kind of embedding cannot be applied to tabular data with varying dimensions and thus cannot serve as the basis for zero-shot learning. 3) Walking embedding regards a fixed number of features as a token representation. # D. Knowledge Distillation

In order to effectively leverage the acquired general knowledge of the LLM while preserving its capacity for generalization, prompting the LLM or fine-tuning it with prompts can be utilized [41], [42]. However, due to the presence of anonymous features in the transaction data, prompt learning is not suitable for our fraud detection task. Nonetheless, direct fine-tuning of the LLM would lead to challenges such as a large number of parameter updates and difficulty in aligning new tasks and optimizing parameters; hence, direct fine-tuning of the LLM itself is avoided. Instead, to maintain the original reasoning capabilities and detection knowledge of the LLM as much as possible, knowledge distillation [33], [43] is employed to guide the model in the fraud detection task. This approach also circumvents direct parameter optimization and alignment of the LLM, focusing solely on enhancing the detection capability without the need for further fine-tuning of any LLM parameters, thus resulting in faster processing speed and generalization ability.

To achieve this objective, we propose the DOC function as the distillation target for fraud detection knowledge, guiding the LLM40FD to evolve into a proficient detector. An intuitive and straightforward explanation is that an LLM can be regarded as a model that has learned a wide range of knowledge [22], [28], yet the centers of different knowledge vary. DOC, however, enables the knowledge center of the model to approach the distribution of normal transactions. In this way, the model can establish the boundaries of fraud-detection behavior. As shown in Fig. 2, the subsequent dual data augmentation makes normal samples approach the knowledge center, while making negative samples that may represent fraudulent behaviors move away from the knowledge center. Thus, the detection ability of the LLM can be distilled.

We assume that the knowledge center for fraud detection ability is represented by $C \in \mathbb { R } ^ { d _ { \mathrm { m o d e l } } }$ . Our objective is to align the unified representation as closely as possible with the knowledge center, thereby activating the LLM’s detection reasoning ability.

$$
{ \mathcal { L } } _ { \mathrm { D O C } } = { \frac { 1 } { B } } \sum \operatorname { S o f t m a x } ( U ) \log \operatorname { S o f t m a x } ( C ) .
$$

By optimizing the above function, the model aims to concentrate the output features $\pmb { U } \in \mathbb { R } ^ { B \times d _ { \mathrm { m o d e l } } }$ as closely as possible around the knowledge center, $C \in \mathbb { R } ^ { d _ { \mathrm { m o d e l } } }$ . LLM40FD deems transactions outside this distribution as fraudulent.

# E. Dual-Augmentation

Due to the inherent imbalance in the training samples, the model is often exposed to a large number of normal (positive) transaction samples and lacks sufficient characterization of fraudulent (negative) transaction behavior. Additionally, the abundance of positive samples during training increases the risk of overfitting [44].

Inspired by the sample augmentation strategies in [45], [46], [47], a Dual-Augmentation strategy based on implicit contrastive learning is proposed to address these issues. This strategy involves generating positive and negative samples to enhance the model’s understanding of fraudulent transaction features and establish clearer decision boundaries for fraud detection. To generate positive and negative samples, the mean $( \mu = \mathrm { m e a n } ( X , \mathrm { d i m } = 0 ) \in \mathbb { R } ^ { 1 \times d _ { \mathrm { m o d e l } } } )$ and standard deviation $( \sigma = \mathrm { s t d } ( X , \mathrm { d i m } = 0 ) \in \mathbb { R } ^ { 1 \times d _ { \mathrm { m o d e l } } } .$ ) of the data within a minibatch are calculated.

To avoid misleading the model by altering the distribution of the original positive samples, a re-sampling process is performed to obtain positive samples:

$$
X _ { \mathrm { p o s } } = \mu + \gamma _ { \mathrm { p o s } } \cdot \sigma \cdot \mathcal { N } .
$$

Here, $\gamma _ { \mathrm { p o s } }$ is used to control the degree of deviation in the distribution center of positive samples, and $\mathcal { N } \in \mathbb { R } ^ { B \times d }$ represents the sampling noise from a standard normal distribution.

Due to the lack of prior knowledge about fraudulent transactions, it is assumed that features that deviate significantly from the original samples (anchors) may indicate fraudulent behavior. Therefore, negative samples are generated by sampling around the original samples.

$$
X _ { \mathrm { n e g } } = X + \gamma _ { \mathrm { n e g } } \cdot \sigma \cdot \mathcal { N } .
$$

Similarly, $\gamma _ { \mathrm { n { e g } } }$ is used to control the degree of deviation in the anchor points during negative sampling.

After generating positive and negative samples, the goal is to align the distribution $U ^ { p } \in \mathbb { R } ^ { B \times d _ { \mathrm { m o d e l } } }$ of positive samples as closely as possible with the distribution center, while pushing the distribution $U ^ { n } \in \mathbb { R } ^ { B \times d _ { \mathrm { m o d e l } } }$ of negative samples away from the center. The process is similar to the one described in (1) and (2). Specifically, by feeding $X _ { \mathrm { p o s } }$ and $X _ { \mathrm { n { e g } } }$ into the walk embedding module and the LLM respectively, we can obtain $U ^ { p }$ and $U ^ { n }$ .

This allows the model to have improved discriminative capabilities, leading to clearer decision boundaries.

$$
\begin{array} { l l l } { \displaystyle \mathcal { L } _ { \mathrm { D O C } } ^ { p } = \frac { 1 } { N } \sum \mathrm { S o f t m a x } ( U ^ { p } ) \log \mathrm { S o f t m a x } ( C ) } \\ { \displaystyle } \\ { \displaystyle \mathcal { L } _ { \mathrm { D O C } } ^ { n } = - \frac { 1 } { N } \sum \mathrm { S o f t m a x } ( U ^ { n } ) \log \mathrm { S o f t m a x } ( C ) . } \end{array}
$$

Hence, the final objective function of LLM40FD is:

$$
\begin{array} { r } { \mathcal { L } = \mathcal { L } _ { \mathrm { D O C } } + \mathcal { L } _ { \mathrm { D O C } } ^ { p } + \mathcal { L } _ { \mathrm { D O C } } ^ { n } . } \end{array}
$$

During the inference stage, we will use the anomaly score based on the DOC function as the evaluation metric, which is expressed as follows:

$$
{ \mathrm { A n o m S c o r e } } _ { \mathrm { D O C } } = { \frac { 1 } { V } } \sum _ { j = 1 } ^ { V } { \mathrm { S o f t m a x } } ( U ) \log { \mathrm { S o f t m a x } } ( C ) .
$$

When the anomaly score of a sample exceeds a preset threshold, the model considers that the sample carries abnormal behavior.

# IV. EXPERIMENTS

# A. Baselines

We evaluate LLM40FD against a comprehensive set of baseline methods, including classical anomaly detection algorithms (OCSVM, KNN, PCA, LOF, and GMM), ensemble methods (IForest, LSCP, and ECOD), and deep learning methods (AE, LIOCAD, DeepSVDD, and LUNAR). Additionally, there is the SOTA model AdvTrans [20] specifically designed for fraud detection. We have transferred these baseline methods to the task of CC fraud detection.

1) Classical Baselines: One-class support vector machine (OCSVM) defines the boundary of data by constructing a hypersphere to enclose normal data points. Any data point outside this boundary is considered an outlier.

KNN predicts the class of a new data point based on the distances between data points. It identifies outliers by calculating the average distance between each data point and its $k$ nearest neighbors.

PCA identifies data points that have unusually large projections along the principal components. These points are considered outliers.

Local outlier factor (LOF) is a density-based method. It calculates the LOF for each data point, and data points with higher LOF values are considered outliers.

Gaussian mixture model (GMM) assumes that data is composed of multiple Gaussian distributions. Data points with low probabilities under the model’s probability distribution are considered outliers.

2) Ensemble Baselines: IForest [48] is an anomaly detection method that builds multiple tree-based models to adaptively discover patterns in anomalous data.

Locally selective combination in parallel outlier ensembles (LSCPs) [49] selects and combines multiple top-performing base outlier detectors based on consensus within local regions using nearest neighbors. This ensemble approach constructs an anomaly score and adapts to local information for detection.

Empirical cumulative distribution based outlier detection (ECOD) [50] estimates the nonparametric form of the underlying distribution of samples using empirical cumulative distribution. It constructs an anomaly score based on this empirical distribution.

3) Deep Learning Baselines: AE is a simple encoder– decoder model composed of multiple perceptron layers, with ReLU activation functions connecting each layer. It reconstructs the input data and uses the reconstruction score as an anomaly score for anomaly detection.

DeepSVDD [51] combines a one-class model with a deep AE. It performs one-class classification on better-represented features to differentiate anomalies.

LUNAR [52] constructs unified local anomalies in message passing of graph neural networks. Basically, it uses neighboring nodes for outlier detection.

LIOCAD [14] is a one-class deep learning method based on a GAN architecture, designed for fraud detection, that generates samples through adversarial generation and distinguishes anomalies through a discriminator.

AdvTrans [20] is a reconstruction model that applies advanced Transformer models to fraud detection, representing the SOTA algorithm in current fraud detection.

# C. Experiment Design

To comprehensively evaluate the performance of LLM40FD, two different experiments were designed: full-shot and zero-shot.

1) Full-Shot and Subset Training: Full-shot (or subset training) setting is a more traditional approach where the model is trained on the whole (or a part of) dataset (e.g., S1) and tested on the testing dataset (e.g., S1) with the same distribution.

2) Zero-Shot: The zero-shot experiment aims to demonstrate the model’s zero-shot transferability and its robustness in detecting fraud across different datasets without additional training. Specifically, the model is trained on one dataset (e.g., S1) but not fine-tuned on the others (e.g., S2, S3, and S4). Its performance is then evaluated on datasets it has not been trained on (e.g., S2, S3, and S4).

These metrics provide a comprehensive evaluation of the model’s capability to accurately detect fraudulent transactions while minimizing false positives and false negatives (FNs).

The calculation of F1 score is as follows:

$$
\mathrm { F 1 } = \mathrm { 2 } \times { \frac { \mathrm { P r e c i s i o n } \times \mathrm { R e c a l l } } { \mathrm { P r e c i s i o n } + \mathrm { R e c a l l } } } .
$$

AUC measures the relationship between the true positive rate (TPR) and false positive rate (FPR) for all possible classification thresholds [55]. The calculation is as follows:

$$
\mathrm { A U C } = \int _ { 0 } ^ { 1 } \mathrm { T P R } ( d \mathrm { F P R } ) .
$$

Here, TPR is a function of FPR, representing the TPR value at a given FPR. This integral represents the area under the curve.

We calculate G-mean as follows:

$$
{ \mathrm { G - m e a n } } = { \sqrt { { \frac { T P } { T P + F N } } \times { \frac { T N } { F P + T N } } } } .
$$

Here, $T P / T P + F N$ represents the recall, and $T N / F P + T N$ can also be referred to as the true negative rate (TNR). Therefore, G-mean can be interpreted as the geometric mean of the Acc in predicting positive and negative classes in the sample, providing a comprehensive measure of Acc for predicting different labels.

The emergence of LLM40FD represents a notable advancement in CC fraud detection. This study effectively addresses the crucial issues of data imbalance, the complexity of large-scale and anonymized transaction data, and the constraints of systemspecific model training. Through extensive experimental validation, LLM40FD has demonstrated its efficacy and efficiency, achieving SOTA performance in both full-shot and zero-shot scenarios. Subsequent research will explore the scalability of this framework and its applicability to other domains within the financial sector and beyond.
